# Smart Parking Optimization Using Metaheuristic Algorithms

## 📌 Project Overview

This project focuses on optimizing parking-space allocation in a smart parking management system. Using a dataset of parking-related information, it explores optimization techniques to improve parking assignments and evaluate system performance.

The project combines data analysis, optimization algorithms, and visualization to study parking allocation strategies and compare their results.

## 🎯 Objectives

- Analyze smart parking management data.
- Formulate the parking allocation problem as an optimization task.
- Apply and compare optimization algorithms.
- Evaluate solution quality, convergence behavior, and performance.
- Visualize results to better understand the optimization process.

## 🧠 Algorithms and Analysis

The project notebook includes experiments and visualizations related to optimization performance. Refer to the notebook for the exact algorithms, configurations, and evaluation metrics implemented.

## 🚀 Getting Started

### 1. Clone the repository

git clone https://github.com/kaoutertazgart/Optimization-Algorithms-Project.git
cd Optimization-Algorithms-Project

### 2. Install the basic dependencies

pip install pandas numpy matplotlib jupyter

Install any additional dependencies required by the notebook.

### 3. Run the notebook

Launch Jupyter Notebook:

Open Smart_Parking_Optimization.ipynb and execute the cells to explore the implementation, experiments, and visualizations.
